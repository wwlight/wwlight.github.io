## WCA 记号

下文公式旁的 `R`、`U'`、`F2` 等是 **WCA 标准记号**（国际魔方协会记谱），播放器步骤条也用同一套。

握法固定为：**白底黄顶**，自己面对前面；字母表示「转哪一面」，不是贴纸颜色。

| 字母 | 面 | 本页颜色 |
| --- | --- | --- |
| `U` | 上面（Up） | 黄 |
| `D` | 下面（Down） | 白 |
| `F` | 前面（Front） | 蓝 |
| `B` | 后面（Back） | 绿 |
| `R` | 右面（Right） | 红 |
| `L` | 左面（Left） | 橙 |

从该面**外侧**看该面：

| 写法 | 含义 |
| --- | --- |
| `R` | 右面顺时针 90° |
| `R'` | 右面逆时针 90°（撇号 `'` = 逆时针） |
| `R2` | 右面 180°（数字 `2` = 半圈） |

`U` / `U'` / `F2` 等同理，只是换面。

## 口诀对照

中文口诀是手法提示，**不等于**面字母。本页「上 / 下 / 左 / 右」专指右手公式里的四步：

| 口诀 | 手在做什么 | WCA |
| --- | --- | --- |
| 上 | 右面近身块向上推 | `R` |
| 下 | 右面近身块向下拉 | `R'` |
| 左 | 顶层向左拨 | `U` |
| 右 | 顶层向右拨 | `U'` |
| 上左下右 | 右手公式 | `R U R' U'` |
| 上右下左 | 左手公式 | `L' U' L U` |
| 前面顺时针 | 前面顺时针 90° | `F` |
| 前面逆时针 | 前面逆时针 90° | `F'` |
| 180° | 该面转半圈 | `F2` `R2` `U2` |

## 七步还原

播放器右侧为 **博罗米恩环** 展开：三个方向各三圈，对应九个可转层；交点上的色点是 54 个贴纸，与左侧立体视图同步。

### 拼底层十字

白心朝下。先将四条白棱转到顶层且白色朝上，使其侧面颜色与该面中心对齐，再将该面旋转 **180°** 转入底层。四条白棱均按此操作。

:rubik-player{stage="white-cross"}

### 拼底层角块

将白角置于目标槽正上方，反复执行 **上左下右**，直至该角落入底层。四个白角均落入后，该步完成。

:rubik-player{stage="white-corner"}

### 还原第二层

先使顶层目标棱块与前面中心颜色对齐。

- 插入左侧槽：棱块先向右移开 → **上右下左** → 将空槽转到右手 → **上左下右**
- 插入右侧槽：棱块先向左移开 → **上左下右** → 将空槽转到左手 → **上右下左**

四条中层棱均归位后，该步完成。

:rubik-player{stage="mid-left"}

:rubik-player{stage="mid-right"}

### 拼顶面十字

公式：**前面顺时针，上左下右，前面逆时针**，即 `F (R U R' U') F'`。

形态顺序为：点 → 小拐 → 一字 → 十字。小拐置于左后方，一字横向放置。此步只需完成顶面黄色棱块，暂不考虑侧面颜色。

:rubik-player{stage="yellow-l"}

:rubik-player{stage="yellow-line"}

### 还原顶面颜色

顶面十字完成后，只需翻转黄色角块。各情形均使用小鱼公式 **下右上右下右右上**，即 `R' U' R U' R' U2 R`。

- 缺两点：左后方放置一块黄色，执行公式后成为小鱼
- 缺四点：背面不应出现黄色，执行公式后成为小鱼
- 小鱼：鱼头置于左上角，执行后顶面全黄

:rubik-player{stage="yellow-two"}

:rubik-player{stage="yellow-four"}

:rubik-player{stage="yellow-fish"}

### 拼顶层角块

口诀：黄面朝向自己，已对齐的一组置于下方，**上右上，下 180°，下左上，下 180°，右 180°**。

演示采用黄顶、成对角块置于后方的等价公式 `R' F R' B2 R F' R' B2 R2`。若尚无成对角块，先执行一次后再观察。四个角均对位后，该步完成。

:rubik-player{stage="pll-corners"}

### 调整顶层棱块

已还原的那一侧面朝向自己，执行 **下左下右，下右下左，上左，右 180°**，即 `R' U R' U' R' U' R' U R U R2`。若无一侧面完全还原，任选一面朝前执行一次。四条棱均对位后，魔方复原。

:rubik-player{stage="pll-edges"}

## 还有哪些方法

入门后宜专精一种方法。本文默认衔接 CFOP。

- **CFOP**：Cross → F2L → OLL → PLL。资料最全，亦是世界纪录的主流方法。本页即为其入门形态。
- **Roux**：两个 1×2×3 块 → CMLL → LSE。步数较少、转体较少，利于单手，更依赖块感。
- **ZZ**：先做 EO（棱向）再 F2L，此后可只转 `RULD`。手法流畅，但 EO 与后期公式门槛较高。
- **Petrus 等**：先拼 2×2×2 再扩展。现已很少作为主方法，多用作块先思路的补充。

不建议同时学习 CFOP 与 Roux。

## 衔接速拧

1. 先以本页七步稳定还原，暂不计时。
2. 将十字改到底面完成，并在观察的 15 秒内看完。
3. 将底层角与中层棱合并为直觉 F2L（仍使用左右手两条公式，视为一对）。
4. 2-look PLL：角块学习 headlights / T、Y，棱块学习 U / H / Z，以替换最后一条长口诀。
5. 2-look OLL：顶面十字加上 Sune、Pi 等七个公式，以替换反复使用的小鱼公式。
6. 全套 PLL（21）→ 全套 OLL（57）→ 高级 F2L。

参考用时：稳定还原 → 1 分钟 → 45 秒（F2L）→ 30 秒（2-look LL）→ 20 秒（全 PLL）→ 15 秒（全 OLL）。

练习要点：

- 计时器使用 [csTimer](https://cstimer.net/)
- 分步练习：单独练习 Cross、F2L、LL
- 先求准确，再提高速度；TPS 服从观察
- 手法单独练习：`R U R' U'`、食指拨动 `U / U'`、推拉 `R / R'`，避免整掌拧转
