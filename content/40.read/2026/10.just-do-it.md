## 13 节实操

年度计划为什么总实现不了、愿景是不是漏了什么、甘特图、三分钟热度、忙完工作再去做年度计划就没戏了。

### 1. 第一章 写给五年后的自己的一封信

焦虑通常是三句：不知道自己要什么；知道要什么，不知道怎么做成；知道怎么做，但做不到。后面的信、九宫格、计划和习惯，对着这三句来。

人按掌控和视角分成四种：

| | 顾眼前 | 看未来 |
| --- | --- | --- |
| 事情推不动 | 回应者：没什么想法，也安于现状 | 空想家：想法多，落实少 |
| 事情推得动 | 执行者：很能干活，没空看自己的未来 | 舰长和指挥官：目标清楚，也做得到 |

![四种人：掌控 × 视角](/read/zhiguan/four-types.jpg)

年度计划从愿景写起，不从今年的清单写起。执行者把别人交代的事做完了，却没为自己想要的日子做过。年的高度先写五年后的信，月的高度再分成习惯和项目，日的高度用 4D。

![现在和过去](/read/zhiguan/now-past.jpg)

![目标横跨反思、执行、计划](/read/zhiguan/goal-time.jpg)

### 2. 不走心的目标是假目标

走脑的计划容易停。没有让自己怦然心动的愿景，就会半途而废。先分清这是自己想做的，还是应该做、不得不做的。想做的才留。

失败通常是四个字：

| | 是什么 | 书里的例子 |
| --- | --- | --- |
| 假 | 不是心里要的，是一时激情 | 路人说你胖，立刻决定减肥 |
| 大 | 超出能力 | 「每天一万步」，难的不是走，是每天 |
| 空 | 写了目标，没有拆到月和天 | 快到年底才想起来还没做 |
| 全 | 目标太多 | 目标一多，说明还不知道自己要什么 |

![小强的年度计划：假、大、空、全](/read/zhiguan/fake-plan.jpg)

五感是视觉、听觉、味觉、触觉、嗅觉。顺序是先用五感看，再感受，最后才用脑。写得太快，就是跳过五感直接用脑。只堆感受、没有具体画面，还是空想。想得很累的时候，上街只观察，不加评判。

![五感](/read/zhiguan/five-senses.jpg)

### 3. 让自己怦然心动的一封信

当仪式写。桌面清空，留本子和笔，做几个深呼吸，找一段没人打扰的时间。

```text
嘿，五年后的我：

我在哪里，和谁在一起：

那天的画面（光线、声音、气味、手里的东西）：

已经做成的事：

还在过的日子：
```

标准只有一个：自己怦然心动。源头没有水，后面挖多少渠都没用。

![五年后的一封信](/read/zhiguan/letter.jpg)

### 4. 第二章 让梦想照进现实

![愿景和现实](/read/zhiguan/vision-gap.jpg)

![愿景和执行力](/read/zhiguan/vision-execution.jpg)

愿景和现实之间有一道缺口，过桥靠的是执行力。卡住时只有两条路：把愿景放低，或者把能力一点点抬上去。又想要、又还做不到，最难受。方法先照着做，做过一段，再长自己的。

![空白九宫格](/read/zhiguan/grid-blank.jpg)

正中写年度主题词，比如「创造现金流」「蜕变」。信里的事按初心放进四周八格。愿景里没提到的格先空着。无缘无故漏掉的那一格，是潜意识的投射，工作事业最容易被漏。

同一件事不知道放哪格，问做它是为了什么。带父母出去，图玩就放休闲，图陪他们就放家庭。

头顶是三种享受：学习的成长、体验突破的愉悦、休闲的放松。左右手是工作和生活，两手都要硬。脚下是三根基：健康、财务、社交。

![九宫格示例](/read/zhiguan/grid-filled.jpg)

![九宫格和身体](/read/zhiguan/grid-body.jpg)

### 5. 三步把模糊的愿景孵化成明确的目标

愿景可以模糊，用来知道往哪走。目标必须明确，不然会犹豫。愿景先孵化成明年的目标。

![愿景孵化为明年目标](/read/zhiguan/hatch.jpg)

|        | 问自己                     | 写下 |
| ------ | -------------------------- | ---- |
| 先定义 | 这句话到底指什么           |      |
| 再计划 | 有哪些做法                 |      |
| 后目标 | 今年先做哪一件，做到哪个月 |      |

财务基本自由，书里的定义是：被动收入大于总支出。被动收入是不用上班也能进账的钱。先把这句话算成数字，再写钱从哪来，最后才是今年要做的那一两件。

一直在忙、一直在学，生活却没变，通常是没沿着自己要的方向。站在路口时，原地不动是唯一算错的选择。走几步发现不通，也算收获。

另外两条书里展开过的定义：体验突破是做以前没做过、稍微出格的事，可以一个月一件；斜杠是多重职业都能带来收入，介绍自己时有多个标签。

### 6. 检查一下年度目标是否合理

先对时间。一天是三个 8 小时：睡、上班、自己支配。人和人的差别在最后那 8 小时。小强第一次写了 19 个目标，一算要 1183 小时，一年能自己支配的只有 728 小时。做个现实的理想主义者：理想不丢，时间得够。

| 这些目标大概要多少小时 |      |
| ---------------------- | ---- |
| 今年能自己支配的小时   |      |

再用 SMART 过一遍。五个字母各问一句，对不上的改到对上再留。

| 字母 | 问一句 | 对不上时长什么样 |
| ---- | ------ | ---------------- |
| S Specific，具体 | 做完是哪一件事，不是哪一类事 | 「学会吉他」——学会没有标准 |
| M Measurable，可衡量 | 做没做成，拿什么数字或动作核对 | 没有次数、斤数、完成的样子，年底没法打勾 |
| A Attainable，够得着 | 以现在的底子，使劲一年能不能碰到 | 「明年年薪 50 万」——跳得太远 |
| R Relevant，相关 | 跟那封信、跟别的目标是不是一件事 | 和今年的主题词没关系 |
| T Time-bound，有期限 | 哪个月之前算数 | 「有空去西藏」等于没有截止日期 |

书里拿来试的几条：

- 「3 个月内学会弹吉他」——卡在 S 和 M
- 「明年年薪 50 万」——卡在 A
- 「有空的时候到西藏玩」——卡在 T
- 「这个夏天瘦 10 斤」——看着具体，没写怎么瘦、用什么秤、掉了又涨算不算
- 「今年内找个女朋友」——五条都站得住

### 7. 第三章 抬头看路与低头走路

目标只有两类。习惯是周期性地做同一件事。项目是好多步骤才能做完的事。两边都有的，比如马拉松，报名和装备按项目，训练按习惯。

| | 容易死在哪 |
| --- | --- |
| 习惯 | 三分钟热度；很努力但看不到效果就放弃；被打断一次就停 |
| 项目 | 拖到最后一刻；盯着细节，丢了整体；好几个项目一起跑就乱 |

做项目时还有三种躲法：觉得方法麻烦，宁可被催；方案选来选去，时间没了；非拖到最后才动。选择困难常常不是性格，是不敢为这个选择负责。还有一种是对拖到最后上瘾，有方法也不改。

一直低头会撞电线杆，一直抬头会掉进坑。听了很多课却没用，就是只输入、不做事。还没开始就想准备齐，想得越多越不敢动。输入堆多了，也会变成逃避动手。

甘特图用来抬头。A4 纸横过来，靠上一条横线切成 12 个月，靠左一条竖线，左边写今年的目标。每个目标用空心框框住起止。每月最后一天改一次：做完涂实，超额涂进下个月，只做一半就涂半格。

先空着，再框起止，每月涂进度。正常、滞后、超前看当月那条虚线。

### 8. 让你低头走路的倒推分解法

简单又具体的事，设个提醒，到点就做。计划太满会有两个结果：像电影被剧透完，兴趣没了；一被打乱就觉得计划没用。缺计划执行力弱，计划过细执行力也弱，中间有一段最佳计划区。

![计划详细度和执行力](/read/zhiguan/plan-detail.jpg)

先把项目放进四格：

|      | 具体                       | 模糊         |
| ---- | -------------------------- | ------------ |
| 简单 | 看一场电影、文身。到点就做 | 先问清楚再动 |
| 复杂 | 带家人去泰国、手头的项目   | 写一本书     |

![简单 / 复杂 × 具体 / 模糊](/read/zhiguan/quadrant.jpg)

模糊又复杂的事先推进学习区，别停在恐慌区。

![恐慌区、学习区、舒适区](/read/zhiguan/zones.jpg)

![写时间管理书推进学习区](/read/zhiguan/zones-moved.jpg)

复杂的从终点往回拆，一直拆到这个月。越靠近现在，越要写成能动手的事。每个项目单独一张清单。

![从终点倒推的节点](/read/zhiguan/milestones.jpg)

![项目清单](/read/zhiguan/project-list.jpg)

![写书项目待办](/read/zhiguan/todo.jpg)

拆开步骤是项目分解。步骤里的难题才要花力气，那是项目化解。两问：怎样让它更简单，怎样让它更具体。书里写书的化法是：先做一门微课把内容梳一遍，散步时收灵感，卡住了找两个朋友碰，先写到三级目录。

一份够用的计划过三关：留余地（坚韧），复杂变简单、难题被化开（简化），做完计划脑子能放下这件事（解放）。

### 9. 第四章 如何培养一个好习惯

三分钟热度本身正常。只靠那股热度把习惯养成就不行。

四段，像推石头上山：靠新鲜感开头，靠方法撑住，靠内心渴求和奖赏冲过自我怀疑，到顶之后石头自己滚，习惯成了自然。

![习惯的四段](/read/zhiguan/habit-stages.jpg)

习惯回路是：暗示 → 惯常行为 → 奖赏，底下是内心的渴求。习惯去不掉，只能换掉中间那个动作。地铁上无聊还在，奖赏还是把时间打发掉，可以把刷微信换成听一段音乐。

![习惯回路](/read/zhiguan/habit-loop.jpg)

![换掉中间的动作](/read/zhiguan/habit-loop-change.jpg)

### 10. 培养习惯的燃料

燃料有两种：热情和痛苦。打卡、提醒、同伴只能监督，对大多数人不够。

一次只养一个。候选的习惯打三列分，0 到 10，加总最高的先做。

![习惯燃料：先空着打分](/read/zhiguan/fuel-blank.jpg)

- 痛苦：这件事解掉我哪块疼，有多深
- 热情：做它的劲有多足
- 时机：眼下的时间、精力配不配。经常出差，就不适合从自己做早饭开始

养成到自己定的标准，就放手，去养下一个。没到标准就停，才是三分钟热度。时间是做减法，不是往同一天里再塞一件。

![习惯燃料打分](/read/zhiguan/fuel-scored.jpg)

### 11. 坚韧的计划比「一定要」的计划更靠谱

四步走到这里：燃料已经选好 → 写习惯培养卡当启动仪式 → 循序渐进的路线 → 记下做了没有。

仪式做三件事：把弹性时间变成硬性时间，让人不用再想，给这段时间一点分量。上班可以是一套固定动作：开电脑、倒水、活动一下、清单放左边、本子放右边、设 25 分钟，然后开始。

会挡住你的事，提前写成「如果……，我会……」。真发生的时候才不会一慌就停。

```text
习惯：

为什么是它（痛苦 / 热情）：

启动仪式（每天同一套动作）：

如果 ________，我会 ________
如果 ________，我会 ________
如果 ________，我会 ________

路线（难度一点点加上去，不要第一天就拉满）：

开始：          完成：
```

![习惯培养卡](/read/zhiguan/habit-card.jpg)

![习惯养成曲线](/read/zhiguan/habit-curve.jpg)

预想是一条平线，现实是上下晃。计划留出这点晃。可以给自己每个月三次中断再回来的机会，三次用完再重来。训练从眼下做得到的强度开始，中间冲一下，再回来，下次再抬高一点。计划越求完美，越容易被打断。

![预想](/read/zhiguan/expect.jpg)

![现实](/read/zhiguan/reality.jpg)

路线顺着事情本身走。健身不是每天都练，而是隔天换部位。每天一万步这种「一定要」，半途而废常常是厌倦，不是不会走。

奖赏是做事时自己的感受，奖励是外面给的东西。感受撑得更久。只在养成之后给外面的奖励，过程里把注意力放在感受上。

### 12. 第五章 如何过一天就如何过一年

忙完工作再做年度计划，就没了。工作、生活、年度计划写在同一张每日清单上，三样是平的。临时变了，先别整张计划作废，变化也算计划里的一项。清单写下来，是为了把它放下，好专心做手头这一件。

没做成，通常是三句：没精力，没有一整块时间，没有立刻去做。早晨精力最好，事情越难掉得越快。中间歇一下，掉得慢一些。整块任务塞不进碎片时间，先拆开再放进去。

### 13. 如何井井有条地度过一个超级忙碌的早晨

临时插进来的事，不要顺手就做。先和手头所有的事比，永远做当前最重要的那件。排序没有标准答案，但要自己承担这个顺序的后果。

付氏工作流：

1. 两分钟能做完的马上做。交代给别人，本身也常常是两分钟的事。
2. 计划内的和突发的，全部写下来。
3. 先看一眼每件到底是什么，再排先后。可以先花几分钟弄清邮件、电话到底是什么事。
4. 重要的先做。不重要的、特别想做的，靠后。
5. 邮件、微信这种不急着回的，有空再处理。

刺激和反应之间有个空隙。经理说立刻过去，不代表真的要第一时间过去。要回应，不必马上做。别人一叫就动，会变成被推着走。两分钟能做完却拖着，后面往往要花更长的时间补。有的事放一放，自己就没了。

做事靠系统，做人用真心。

## 划线摘录

> 一个走心的计划，加上只管去做的觉悟就可以摆脱焦虑。

> 想不到的做不到，想不清楚的做不好。愿景可以是模糊的大方向，让我们知道往哪儿走，并且充满动力就可以了。但目标一定是明确、具体、清晰的。

> 人生除了活得有意义，还要活得有意思。

> 人左右手握着的是工作和生活的平衡，两手抓，两手都要硬。人头顶上是三种享受：学习过程中的成长享受，体验突破的愉悦享受，还有休闲娱乐的放松享受。
