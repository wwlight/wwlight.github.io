德国两位咨询师写的。一个人眼里的蚊子，可以是另一个人眼里的大象。

## 蚊子、大象、激动

MEA 是三样东西：蚊子、大象、情绪激动。

蚊子是眼前这件事，常常很小。大象是这件事撞上的旧需求。激动是两者叠在一起以后的反应。踩一脚会烦，烦成那样，是因为后面还有一头大象。

长期没有爱、没有安全感、觉得低人一等或被误解，情绪会一直受影响。基本需求没被满足，大象就留下来。

让人不安的是对事情的想象。在对的时间、用对的方式、出于对的原因、对着对的人发火，并不容易。

## 需求

需求出现在现状和想要的状态之间。人更容易看见还没被满足的那一半。

有的需求靠别人的行为才满足得了，会带来依赖。有的需求自己可以满足。只追一种，其余的就失去平衡。平衡会随人生阶段变。

独立自主是留出体验不同生活的自由。

时间和精力实际花在哪里，和自己以为重要的地方，常常不是一处。知道可以放弃什么，才知道现在最要紧的是什么。

## 七头大象

生活经历留下七种典型。括号里是书中的人。

| 大象 | 这句话                 | 人怎么保护自己                         |
| ---- | ---------------------- | -------------------------------------- |
| 一   | 我害怕失去呵护         | 丽莎。对谁都好，怕冲突、怕被拒绝       |
| 二   | 我没有受到尊重         | 斯特凡。价值感靠别人的认可，容易先防一手 |
| 三   | 我无法划定自己的界限   | 彼得。怕一划界线，关系就没了           |
| 四   | 我渴望得到重视和尊重   | 安娜。先满足别人，自己的需求说不出口   |
| 五   | 我感到格格不入         | 塞巴斯蒂安。觉得要做出成绩才配待在里面 |
| 六   | 我总是不得不退让       | 西比莉、保罗、安妮特。冲突里退，事后反复想 |
| 七   | 没有人在乎我           | 马库斯。干脆谁也不靠                   |

二和四都跟尊重有关。二是「别人没把我当回事」。四是「我得先让别人满意」。

## 怎么找到自己的那头

先看生活质量对你是什么意思，再写生活里真正需要什么。重视、却长期空着的那几项，就是受伤的点。需求之间会打架，先排顺序。

激动的时候做一张表。对象分成他人、亲近的人、一起做事的人。0 是没什么感觉，1 是短暂的不自在，2 是反应强或者久。分高的那一格，往大象上追。

小事上发火，就问三句：我需要什么，对方需要什么，这件事里两个人真正需要什么。

## 把平衡找回来

先分开蚊子和大象。深呼吸，在心里慢慢数到 10，给身体一点距离。别要求自己此刻就必须冷静。留意当天的小成功、放松、一句好话。气味也可以把一段好的经历带回来。

接受现实，才换得了做法。旧的自我保护是当时用来过日子的。现在用能满足需求的做法换掉它。小小的成功要自己记一笔。

看自己：知道长处，用这些长处，弱点承认并且收一收。过去那道墙，以现在的身高看，往往只是矮墙。记忆还停在当时，人就会用小孩的办法对付已经变小的障碍。

七头大象可以当向导。每头对应一个拉锯：

| 大象 | 两边                         |
| ---- | ---------------------------- |
| 丽莎 | 寻求安全感，还是坚持自我     |
| 斯特凡 | 受人尊重，还是自我尊重     |
| 彼得 | 独立自主，还是彼此支持       |
| 安娜 | 讨好别人，还是做自己         |
| 塞巴斯蒂安 | 要归属，还是保持独立   |
| 西比莉 | 公平高于一切，还是也顾自己的利益 |
| 马库斯 | 独自应对，还是依赖别人     |

目标用肯定句来写，比如「我想先搞清楚问题」。害怕被叮的时候，每一次小的做到，勇气会再带出勇气。需求会变，平衡要反复找。

精力放在和能力、价值观、真正的需求一致的事上。这种用力会变成下一次的能量。以前觉得是浪费的活动，也可以先找出它有用的一面。

## 划线摘录

> 让人不安的不是事物本身，而是我们对事物的想象。

> 独立自主并不是要求自己必须独立，而是让自己有体验各种生活的自由。

> 相对于已满足的需求，我们更容易注意到未满足的需求。

> 接受现实是迈向改变的第一步。

> 如果因为所谓的小事而动怒，请你自问：我需要什么？对方需要什么？或者我们两人在这种情况下真正需要什么？

> 虽然过去的事情无法改变，但与童年时期的困境相比，今天的你已经不再那么无助和缺乏保护了。

> 总是设定正面的目标。不要用否定的方式，而是肯定的方式。

> 你所做的事情与你的能力、价值体系以及真正重要的需求越一致，它对你的幸福感就越有帮助。

> 我们因微不足道的小事陷入情绪风暴，很可能意味着我们在情感上混淆了过去和现在。因为当下的情绪唤醒了旧时的感觉，激活了过去的应对模式，而这些往往是不合时宜的。

> 在孩提时代我们就被灌输这样的观念：满足他人的期望比表达自己的感受和需求更重要。在这种观念中长大的人不会明白自己真正想要的是什么，可能会一直处于不快乐状态。

> 如果我们压抑住那些误以为不该有的情绪，就会切断我们通向重要需求的路径。

> 没有人能始终保持强大、自信、冷静。所以，生气、恐惧、担忧、受伤等不愉快的情绪，首先都是对烦心事最正常的反应。

> 我们总是试图让自己免受痛苦情绪的干扰，却很少去思考这些蚊子般的小事其实是我们内在需求受挫的提示。

> 没有人会毫无缘由地因小事而生气，因为没有一种情绪是突然爆发的。很多时候我们只看到了蚊子，然而它的刺可能会触及我们内心的更深层面。

> 当我们学会坦率地表达自己的敏感和脆弱时，对方才会有机会更好地理解我们，我们也能更好地理解他人的痛点。

> 当我们面对难以掌控的高压时，往往倾向于回归旧时应对模式，而不是尝试新的方式，这样蚊子就变成了大象。
